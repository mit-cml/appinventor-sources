# Security Policy

## Supported Versions

MIT App Inventor is a web based platform. The currently supported
versions are marked below.

| Version | Supported          |
|---------|--------------------|
| nb207+  | :white_check_mark: |
| < nb207 | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security
vulnerability, please do **not** open a public issue. Instead, report it
privately using one of the following methods:

- **Email:** Send details to `security@appinventor.mit.edu` with `[SECURITY]` in the subject line.

### What to Include
To help us triage and resolve the issue quickly, please include:
- A description of the vulnerability and its potential impact
- Affected versions, files, or configurations
- Step-by-step instructions or a proof-of-concept (PoC) to reproduce the issue

## Response & Disclosure Process

- **Acknowledgment:** We aim to acknowledge receipt of your report within 48 hours.
