MIT App Inventor has been open source since 2012 and, as of 2026 has had more than 215 [contributors](https://github.com/mit-cml/appinventor-sources/graphs/contributors?all=1).

The project uses the [Apache 2 License](https://github.com/mit-cml/appinventor-sources/blob/master/LICENSE) and it has been used by millions of people all over the world. Use the links above to find the source code and join us in the community if you are interested in contributing or just want to be informed about the project.
